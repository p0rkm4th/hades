# FAQ

**Does HADES require Proxmox?** No. Standalone is the reference path.

**Does it require a cloud account?** No. Local CPU/GPU or an existing private
model server is supported.

**Will it copy my old HADES identity?** No. Restore is explicit and separate.

**What if a model is unavailable?** HADES reports the configured route or
failure; it does not silently export protected context or broaden authority.
