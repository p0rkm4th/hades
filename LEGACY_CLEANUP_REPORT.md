# Legacy Cleanup Report

This public-safe report records the preservation policy without identifying
private workspaces, remotes, branches, users, hosts, or data locations.

## Policy

- Source and architecture lessons may be preserved as references.
- Databases, backups, browser profiles, logs, credentials, and owner/runtime
  data remain outside this repository.
- Ambiguous artifacts are preserved until ownership and retention are proven.
- Regenerable build output and disposable caches may be removed only after a
  bounded, reversible review.

## Result

No owner data or legacy runtime state was imported into HADES. This repository
contains only the fresh composition scaffold, public-safe documentation, and
maintainable UI extension assets.
