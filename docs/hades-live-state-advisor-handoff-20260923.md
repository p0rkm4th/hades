# Live-state handoff policy

Current deployment provenance, source reachability, private runtime state, and
owner dogfood results belong in `hades-infra`. The previous detailed handoff is
retained in the private archive at
`docs/private-public-hades-source-archive-20261001/`.

For current engineering, inspect the active checkout and deployment provenance
first, then query each canonical source directly. Label every claim as live,
recent, stale, synthetic, historical, or unknown. Do not use this public page
as current operational evidence.
