# Hermes overlay provenance

The active deployment's repository path, overlay digest, service units, and
runtime provenance are private operational records in `hades-infra`. The
historical deployment-specific inventory is retained in the private archive at
`docs/private-public-hades-source-archive-20261001/`.

Public HADES documents the overlay compatibility contract and synthetic tests.
Production provenance must be checked on the deployment host before a release
or rollback; this page is not a live status source.
